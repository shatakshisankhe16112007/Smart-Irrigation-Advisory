# AI-Based Smart Irrigation Advisory for Sugarcane

## Use Case
KJS-AGR-01 Irrigation Advisory System for Sugarcane Crop using AI and Sensor-Based Technology.

## Problem Statement
To analyze soil moisture, rainfall and temperature data and generate irrigation recommendations using descriptive statistics and AI-based decision rules.

## Dataset
20 observations of:
- Soil Moisture (%)
- Temperature (°C)
- Rainfall (mm)

## Statistical Concepts Used
- Population and Sample
- Mean
- Median
- Mode
- Variance
- Standard Deviation

## AI Decision Rules

Moisture < 25%      -> Irrigate Immediately

25% to 30%          -> Irrigate Within 24 Hours

30% to 35%          -> Monitor

Above 35%           -> No Irrigation Required
